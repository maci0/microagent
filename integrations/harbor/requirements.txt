# What microagent_agent.py imports: the Harbor framework it plugs into. The
# adapter subclasses harbor.agents.base.BaseAgent, takes a
# harbor.environments.base.BaseEnvironment and reads
# harbor.models.agent.context.AgentContext, so a Harbor release that moves or
# renames any of them breaks the adapter, and `harbor run` is what the numbers
# in docs/benchmark.md come from. Pinned exactly, so a benchmark and the adapter
# that produced it are the same pair on any machine.
#
# Install into the venv the README names:
#
#     uv pip install --require-hashes --python ~/harbor-venv/bin/python \
#       -r integrations/harbor/requirements.lock
#
# requirements.lock is this pin plus Harbor's whole dependency tree, every
# artifact hashed, so the venv a score was measured in is the same one on the
# next machine and an artifact that changes after publication fails the install
# rather than benchmarking the adapter. It is uv's output, not a hand-written
# list, and this file is its only input:
#
#     uv pip compile --generate-hashes --python-version 3.12 --universal \
#       -o integrations/harbor/requirements.lock \
#       integrations/harbor/requirements.txt
harbor==0.23.0
